## Categorías del catálogo

Al iniciar el backend se crean en MongoDB, si todavía no existen, las categorías `Electrónica`, `Hogar`, `Moda`, `Deportes`, `Libros` y `Otros`. Las categorías adicionales ya guardadas se conservan. El formulario obtiene sus opciones desde `GET /api/categorias`.
