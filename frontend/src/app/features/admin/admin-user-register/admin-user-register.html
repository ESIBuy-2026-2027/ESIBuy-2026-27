Alta de Cuenta de Usuario

Como administrador, introduce los datos de la nueva cuenta. Selecciona si se registrará un Cliente o un Vendedor.

Información del Vendedor

Datos obligatorios para la identificación de la cuenta.

Información del Cliente

Datos obligatorios para la identificación de la cuenta.

El nombre es obligatorio. El nombre debe tener entre 2 y 25 caracteres.
Los apellidos son obligatorios. Los apellidos deben tener entre 2 y 50 caracteres.
El email es obligatorio. Formato de email no válido (ejemplo: usuario@ejemplo.com).
El documento de identidad es obligatorio. No puede superar los 20 caracteres.
El teléfono debe contener exactamente 9 dígitos.
La fecha de nacimiento es obligatoria. El cliente debe ser mayor de edad.
El nombre comercial es obligatorio. El nombre comercial debe tener entre 2 y 100 caracteres.
Debes seleccionar una categoría principal.

Seguridad de la Cuenta

Establece la contraseña inicial para el usuario.

La contraseña es obligatoria. La contraseña debe tener al menos 12 caracteres. Debe contener mayúscula, minúscula, número y carácter especial.
Debe repetir la contraseña. Las contraseñas no coinciden.
